# AERIS-3D: Architecture & Overview

## Architecture Overview
AERIS-3D is a unified 3D reconstruction and height estimation platform designed for aerial and satellite imagery. At its core, the architecture consists of:
1. **Input Manager**: Ingests raster data, normalizes image formats, and preserves critical georeferencing metadata if present.
2. **Depth Engine**: Utilizes state-of-the-art monocular depth estimation models (such as Depth-Anything-V2, fine-tuned on the GAMUS subset) running in mixed precision to generate dense relative surface models from 2D pixels.
3. **Terrain Calibration Solver**: A dynamic geometric translation layer that anchors relative depth maps to real-world coordinates and absolute elevations when possible.
4. **Interactive Viewer (Frontend)**: A Three.js based web application exposing tools for 3D flythrough (PointerLock), on-cursor height raycasting, slope analysis, and reference ground-truth toggling.

## Georeferenced vs. Non-Georeferenced Pipelines

The system dynamically adapts its processing path depending on the metadata of the input image:

### 1. Georeferenced Pipeline (GeoTIFFs) -> Absolute DSM
When the `InputManager` detects a GeoTIFF with coordinate reference system (CRS) data and bounding boxes:
- The `TerrainSolver` automatically intercepts the geographic bounds.
- It fetches the corresponding true geographic terrain elevation data (e.g., Copernicus 30m DEM) directly from AWS S3 via `rasterio`.
- The relative depth generated by the neural network is mapped to the bounding box, rescaled based on structural variance, and layered on top of the actual geographic base terrain.
- **Output:** An absolute Digital Surface Model (DSM) saved as a GeoTIFF with real-world CRS constraints and absolute elevation values (in meters).

### 2. Relative Pipeline (PNGs/JPGs) -> Relative rDSM
When the input is a standard, unreferenced image format (like PNG or JPG):
- The system bypasses geographic DEM fetching since there is no spatial anchor.
- The depth map generated by the neural network is purely normalized across the image's internal dynamic range (0.0 to 1.0).
- **Output:** A non-georeferenced relative-rDSM saved as a standard TIFF. This is useful for structural analysis and purely visual 3D reconstruction without geographic grounding.

## Running the Web Demo

The AERIS-3D platform includes an interactive, browser-based 3D workspace.

1. Ensure your Python virtual environment is activated.
2. Launch the FastAPI server which also serves the frontend:
   ```bash
   venv\Scripts\python.exe backend\main.py
   ```
3. Open your web browser and navigate to: `http://127.0.0.1:8000`
4. The viewer allows you to:
   - Upload new satellite images or select test presets.
   - Run inferences on the fly.
   - Toggle **Fly Mode (PointerLock)** for immersive flythroughs with collision boundaries.
   - Point at the mesh to get live **Height** readouts.
   - Use the **Slope Tool** by clicking two geographic points to calculate gradient percentages and angles.

## Evaluation Results

The underlying depth estimation model was evaluated against ground truth labels from the GAMUS dataset (Washington D.C. split) and a customized true-terrain georeferenced test tile (Mussoorie).

| Category | RMSE (m) | MAE (m) | Correlation (r) |
| :--- | :--- | :--- | :--- |
| **government_urban** (DC) | 8.39 | 6.11 | 0.35 |
| **hilly** (Mussoorie) | 274.47 | 234.87 | 0.23 |

### Assessment & Limitations
* **Government/Urban (Washington D.C.):** While the model successfully captures the fundamental structural layout (correlation of 0.35 indicates buildings are correctly raised relative to roads), the mean absolute error of ~6.1 meters reveals that the model struggles to accurately predict the absolute vertical heights of diverse structures—a limitation expected given the extremely short 1-epoch fine-tuning run on a tiny subset.
* **Hilly (Mussoorie):** The catastrophically high absolute errors (MAE ~234m) demonstrate that while the network can isolate localized visual textures (like tree canopies), it completely fails to infer massive, low-frequency geographic elevation gradients because it was fine-tuned strictly on urban Above-Ground-Level (AGL) data rather than true geomorphological terrain.
